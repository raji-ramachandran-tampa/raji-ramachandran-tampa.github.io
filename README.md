## Updating projects and resume

Add or revise project entries in the Projects section of `index.html`, using the public repository URL and accurate implementation and validation status. Keep the project descriptions in `resume/Raji_Ramachandran_Resume.md` aligned, then update the Word copy at `resume/Raji_Ramachandran_Resume.docx`. The website download link points to that stable filename.

Commit and push changes to the repository default branch to publish through GitHub Pages. Review the website after deployment. New repositories are not added automatically; update these descriptions when introducing a project or when its capabilities change.
